# Sprint Point Days

Herramienta para planificar y gestionar sprints de desarrollo.

## Inicio rápido

```bash
pnpm install
pnpm dev
```

## Stack

- **Next.js** — Framework React
- **TypeScript** — Type safety
- **Biome** — Linting y formatting

## Estructura

- `app/` — Componentes y páginas
- `app/components/sprint-planner.tsx` — Planificador principal
- `app/lib/mock-data.ts` — Datos de prueba
